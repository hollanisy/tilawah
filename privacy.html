Kebijakan Privasi — Tilawah

Terakhir diperbarui: 4 September 2026

Tilawah adalah aplikasi pribadi untuk mencatat progres bacaan Al-Qur'an, terjemahan, hafalan surah, dan hafalan doa harian. Halaman ini menjelaskan bagaimana aplikasi menangani data pengguna.

Data yang disimpan

Aplikasi menyimpan data berikut, yang seluruhnya kamu masukkan sendiri saat menggunakan aplikasi:

  • Status surah yang sudah dibaca dan terjemahannya
  • Status hafalan per surah
  • Status hafalan doa harian
  • Catatan bacaan terakhir dan riwayatnya

Bagaimana data disimpan

Jika kamu memilih untuk menghubungkan akun Google, data di atas disimpan sebagai satu berkas JSON di ruang penyimpanan aplikasi milikmu sendiri di Google Drive (App Data Folder) menggunakan akses drive.appdata. Berkas ini:

  • Tidak terlihat di tampilan Google Drive biasa milikmu
  • Hanya bisa diakses oleh aplikasi ini menggunakan akun Google yang sama
  • Tidak pernah dikirim ke server pihak ketiga mana pun — aplikasi berjalan sepenuhnya di peramban (browser) kamu dan berkomunikasi langsung dengan API Google Drive

Jika kamu tidak menghubungkan akun Google, data hanya tersimpan secara lokal di peramban perangkatmu.

Data yang tidak dikumpulkan

Aplikasi ini tidak mengumpulkan, membaca, atau membagikan berkas lain di Google Drive-mu, tidak menggunakan pelacak pihak ketiga, dan tidak menampilkan iklan.

Menghapus data

Kamu dapat memutuskan sambungan akun Google kapan saja melalui tombol "Putuskan" di aplikasi, atau mencabut akses aplikasi ini dari halaman izin akun Google. Menghapus akses akan menghentikan sinkronisasi; berkas data di Drive dapat dihapus manual melalui pengaturan penyimpanan aplikasi di akun Google-mu.
