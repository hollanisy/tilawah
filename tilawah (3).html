Sambungkan ke Google Drive

Untuk sinkron ke Drive-mu sendiri, buat Google OAuth Client ID sekali saja (gratis, di akun Google-mu):

  1. Buka Google Cloud Console → Credentials
  2. Buat project, aktifkan "Google Drive API"
  3. Buat Credential → OAuth Client ID → tipe "Web application"
  4. Di "Authorized JavaScript origins" tambahkan alamat tempat file ini di-hosting (mis. domain GitHub Pages-mu)
  5. Salin Client ID-nya, tempel di bawah ini
